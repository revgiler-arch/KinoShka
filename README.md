# КиноШка

Кинотеатр без рекламы для Android-телефонов и Android TV.

- **Каталог** — Кинопоиск (через неофициальный API kinopoisk.dev): постеры, описания, рейтинги, подборки.
- **Просмотр** — только у правообладателей: фильм ищется на YouTube, VK Видео и RuTube, но берётся
  лишь с каналов из белого списка (Мосфильм, Ленфильм, Киностудия Горького, Союзмультфильм…)
  или с официальной отметкой площадки (для VK — только белый список: галочка VK ставится и частным лицам). Трейлеры, обзоры и нарезки отсекаются по длительности и названию.
- **Телевизор** — иконка в лаунчере Android TV, всё управляется пультом, фокус хорошо виден;
  в плеере ←/→ перематывают, ОК — пауза и меню.
- **Без аккаунта** — «Продолжить просмотр» и позиции фильмов хранятся на устройстве.

## Первый запуск

1. Получите бесплатный ключ у Telegram-бота **@kinopoiskdev_bot**.
2. Откройте КиноШку → ⚙ Настройки → вставьте ключ → «Сохранить ключ».

## Сборка

APK собирает GitHub Actions при каждом пуше и выкладывает в Releases под тегом `latest`
(приложение само проверяет там обновления). Для подписи нужен секрет репозитория
`SIGNING_KEY_PASS` (Settings → Secrets and variables → Actions): им расшифровывается
`app/kinoshka.keystore.enc`.

Каждый день workflow `Auto-update extractor` проверяет новую версию NewPipeExtractor
(библиотека для YouTube) и, если она вышла, пересобирает приложение.

## Устройство кода

| Файл | Что делает |
|---|---|
| `data/Kinopoisk.kt` | каталог, подборки, поиск, кеш ответов на диске |
| `data/Rutube.kt` | поиск на RuTube и ссылка на поток HLS |
| `data/VkVideo.kt` | поиск на VK Видео и ссылка на поток HLS (без входа) |
| `data/YouTube.kt` | поиск на YouTube и выбор потоков (H.264 до 1080p + AAC) |
| `data/SourceFinder.kt` | сопоставление «фильм ↔ видео», белый список, оценка совпадения |
| `player/PlayerActivity.kt` | полноэкранный плеер Media3, управление пультом, продолжение с места |
| `ui/*` | экраны на Compose: главная, поиск, карточка фильма, настройки |
